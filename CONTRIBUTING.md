# Contributing

Contributions are welcome through issues and pull requests.

1. Create a virtual environment and install `requirements.txt`.
2. Make focused changes with tests.
3. Run `python -m pytest` and `python -m compileall -q src tests scripts`.
4. Do not commit original monthly M100 tarballs or confidential telemetry.
5. Preserve M100 ExaData attribution for any derived data.
